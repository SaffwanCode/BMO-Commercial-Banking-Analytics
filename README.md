
# BMO Commercial Banking Analytics

## Project Overview
An independent financial analytics project using publicly available BMO financial data to evaluate banking performance, lending trends, profitability, and credit risk.

The objective is to transform financial data into actionable business insights that support strategic decision-making.

## Project Status
- In Progress

## Business Objectives
- Analyze historical revenue and profitability trends.
- Evaluate loan and deposit growth.
- Assess credit risk and provisions for credit losses.
- Compare performance across banking segments.
- Develop an interactive executive dashboard.
- Provide data-driven strategic recommendations.

## Technology Stack
- Python (Pandas, NumPy)
- SQL
- Microsoft Power BI
- DAX
- Microsoft Excel
- GitHub

## Data Source
Publicly available financial reports and supplementary financial information published by BMO Financial Group.

## Project Workflow
1. Data collection
2. Data cleaning and transformation
3. Data modeling
4. SQL analysis
5. Dashboard development
6. Business insights and recommendations

## Expected Deliverables
- Cleaned financial datasets
- Python data processing scripts
- SQL analytical queries
- Interactive Power BI dashboard
- Executive summary and strategic recommendations
